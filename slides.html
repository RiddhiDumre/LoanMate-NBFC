4. Decisions & Trade-offs
What We Built vs. What We Deliberately Excluded
Product Judgment Matrix
What We Deliberately Built What We Explicitly Omitted
Upfront Range Calculator: Gives immediate borrowing range before asking for sensitive KYC. Mandatory OTP Login Wall: Replaced upfront OTP wall with frictionless eligibility exploration.
Entity-Tailored Document Hub: Shows exact checklist upfront on the result screen. Generic One-Size-Fits-All Forms: Excluded uniform checklists that confuse sole proprietors vs Pvt Ltds.
Silent Processing & Auto-Fill: Extract document data silently into standard text fields. Flashy "AI Assistant" Overlays: Omitted chat bots and AI badges that increase user skepticism.
Single-Page Progressive Flow: Keeps context intact without confusing multi-page redirects. Deep Multi-Step Wizard: Removed multi-page step bars that cause cognitive fatigue.

4. Role of Artificial Intelligence
Where AI Genuinely Helps (and Where It Doesn't)
Pragmatic AI Utility

Where AI Adds Real Value

  • • Document Parsing (OCR & NLP): Instantly extracting name, GSTIN, and line items from bank statement PDFs.
  • • Fraud Detection: Cross-referencing name spellings between PAN and Bank Statements.
  • • Unstructured Document Formatting: Converting diverse bank PDF templates into standard JSON schema.

Where AI Is NOT Used (Rule Engine)

  • • Credit Score & Loan Eligibility: Uses deterministic NBFC financial formulas (not LLM halluctionation).
  • • Form UI Navigation: Standard predictable UI controls instead of conversational chat bots.
  • • Regulatory Compliance: Hardcoded RBI consent text and explicit check boxes.

4. Product Details & Edge Cases
Handling Real-World UX Edge Cases
System Resilience

1. Blurry / Low Quality PDF

System fails to read document text clearly during extraction.

Fallback: Gentle alert with option to manually fill fields or re-upload clear image.

2. Name Mismatch Across Docs

PAN card lists "Rajesh Kumar", Bank Statement lists "Rajesh K."

Fallback: Fuzzy matching flags record for background underwriter review without blocking application.

3. Missing ITR Returns

Small proprietor does not file formal ITR income returns.

Fallback: Alternate surrogate path evaluating 12-month bank cash inflows.
